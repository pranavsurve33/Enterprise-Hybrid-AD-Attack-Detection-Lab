Enterprise Hybrid AD Attack & Detection Lab

Most CTF labs teach you to break one box. This one teaches you what happens after — how a single misconfigured trust relationship or over-privileged service account turns into domain compromise, and what it actually looks like on the defensive side while it happens. Every attack path here is mirrored by a detection built to catch it.

Active Directory Azure AD Hybrid Join Sysmon + Sigma MITRE ATT&CK mapped Purple team format

Lab architecture

A small hybrid identity environment, sized to be buildable on a single host with nested virtualization: one on-prem forest, one Azure AD tenant synced via Entra Connect, and a logging tier that sees everything before the attacker does.
